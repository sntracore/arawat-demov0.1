## Long-term Knowledge

### Gotcha

<!-- lore:01a0151d-991a-7181-b3b9-39b06638e31b -->
* **Lovable asset URLs (\_\_l5e/assets-v1) break on self-hosted deploys**: Trap: Lovable-generated .asset.json files reference internal paths like \`/\_\_l5e/assets-v1/{id}/{filename}\` that only resolve within Lovable's platform. These look correct in dev on Lovable but silently fail (blank/broken media) when deployed to Netlify or any self-hosted target. Fix: Replace Lovable asset references with static assets stored in the repo (e.g. move hero-cosmos.mp4 into \`src/assets/\` and import directly). Delete the corresponding \`.asset.json\` file and its Lovable-specific URL from component code.

<!-- lore:01a01518-5884-79dc-a899-fce08029cd59 -->
* **Remove .lovable/project.json to disconnect from Lovable**: Trap: Keeping .lovable/project.json may maintain connections to Lovable platform, causing deployment conflicts or unwanted dependencies. Fix: Remove the file from staging and ensure it's deleted or ignored, as done during arawat setup.

### Pattern

<!-- lore:01a01518-587f-702a-93a9-44fe43068091 -->
* **Gitignore for .env\* and .netlify/**: Always add .env\* files to .gitignore to prevent accidental exposure of secrets. Include .netlify/ directory to ignore build artifacts and local Netlify configuration, avoiding unnecessary commits.

<!-- lore:01a01518-5872-7f54-a58d-56792c0e9fe0 -->
* **Netlify deployment with @netlify/vite-plugin-tanstack-start**: For deploying TanStack Start apps to Netlify, integrate @netlify/vite-plugin-tanstack-start in vite.config.ts and create netlify.toml with build command 'bun run build' and publish directory 'dist'. This ensures proper SSR and asset handling on Netlify.
